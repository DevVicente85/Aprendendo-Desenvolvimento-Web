Principais Formatações

-Negrito / Destaque

Em negrito utilizando a tag B (não semântica).

Em destaque utilizando a tag STRONG (semântica).

-Itálico / Ênfase

Em itálico, com a tag I (não semântica).

Em ênfase também com a tag EM (semântica).

-Texto Marcado

Um texto marcado utilizando a tag MARK.

Um texto marcado com outro background color.

-Texto Grande e Pequeno

Texto Grande com a tag BIG, e Texto Pequeno com a tag SMALL.

-Texto Deletado

Texto como excluído com a tag DEL.

-Texto Inserido e Sublinhado

Um texto como inserido com a tag INS.

Um texto com Sublinhadocom a tag U (não recomendada).

Outras Formatações

-Texto Sobrescrito

Dá para ter um texto sobrescrito, como por exemplo: x20 + 3

-Texto Subscrito

Também é possível usar texto subscrito, como por exemplo: H2O.

-Codigo-Fonte/Pré Formatação

Um pequeno codigo de Impar ou Par na linguagem de estudo Portugol

        
        inteiro x
        escreva("Digite um Numero Inteiro")
        leia(x)
        se (x % 2 == 0) {
            escreva("Este Numero é Par")    
        }
        se nao {
            escreva("Este Numero é Impar") 
        }
