-Simbolos:

Para os simbolos existe uma regra diferente em que ainda é preciso colocar o & e você precisa saber qual o codigo, tanto o numero quanto o nome especifico do que você quer:

Por exemplo o simbolo do EURO ele se escreve o euro; ou também #8364; resultado em €.

Exemplos de simbolos:

  • © = Copyright
  • ® = Marca Registrada
  • ← Flecha Para Esquerda
  • ↑ = Flecha Para Cima
  • → = Flecha Para Direita
  • ↓ = Flecha Para Baixo
  • ♠ = Espadas
  • ♣ = Paus
  • ♥ = Copas
  • ♦ = Ouros
